# Stackable Mobs Addon

**Make mobs stackable like boats and solid like happy ghast - without modifying vanilla entity JSON!**

Stand on top of any mob! This addon makes mobs behave like solid platforms, perfect for mob farms, transportation, and creative builds. Works with most vanilla mobs and custom mobs, and **does not disable achievements**. The collision box is based on the actual entity's collision box.

---

## ✨ Features

- **🔄 Stackable Mobs**: Stand on top of any mob just like you can with boats
- **🛡️ Solid Collision**: Mobs become solid when you're on top of them
- **⚡ Farm-friendly**: Optimized for mob farms
- **🎯 Compatibility**: Works with most vanilla mobs and custom mobs
- **✅ Achievement-Friendly**: Achievements remain enabled
- **🔧 No Modifications**: Works without modifying vanilla entity files

---

## 🚀 Installation

1. Download the `.mcpack` file
2. Double-click to import into Minecraft (or use Import in Minecraft) or rename to .zip for Desktop.
3. Activate the addon in your world settings
4. Load your world and start uncovering what's possible!

---

## 🎮 How to Use

Simply jump on top of any mob! The addon automatically:

- Detects when you're above a mob
- Creates a solid collision box so you can stand on it
- Removes the collision box when you step off

That's it! No configuration needed.
